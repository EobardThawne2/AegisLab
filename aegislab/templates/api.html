PHASE 1 · READ-ONLY API

Foundation endpoints

Local backend operations. No participant authentication or evaluation endpoints are implemented yet.

GET /health/live ↗

Backend liveness. A successful response confirms that the HTTP application is serving requests; it does not check the database.

GET /api/status ↗

Live database and schema checks with safe status details. The response never includes the database URI or credentials.

GET /health/ready ↗

HTTP 200 only if database connectivity and the recorded migration match. HTTP 503 otherwise.

Machine-readable OpenAPI schema ↗ · All endpoints are read-only. Apply migrations using the documented uv command.
