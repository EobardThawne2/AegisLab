Application endpoints

HTML/CSS reference for the local prototype. Bounded mock fixtures execute in the trusted controller; isolated workers are deferred. Version and evaluation APIs require an authenticated session.

Method / endpointActual behavior
GET /health/liveBackend liveness only.
GET /health/ready200 only when the database, migration checksums, required tables and signing key are ready; 503 otherwise.
GET /api/statusCurrent safe database/schema status; no credentials.
POST /api/auth/loginUsername/password JSON; creates an HttpOnly session cookie and returns a CSRF token.
GET /api/auth/meThe authenticated participant and its CSRF token.
POST /api/auth/logoutRevokes the current session; requires X-CSRF-Token.
GET, POST /api/submissionsList own metadata or validate/save an immutable private JSON document. POST requires X-CSRF-Token.
GET /api/submissions/{version_id}Owner-only full document. Unknown or unauthorized versions return 404.
GET /api/evaluation-referencesEvaluator-only coordination metadata without private document bodies.
GET, POST /api/evaluationsList authorized evaluation locks or create a lock using four fixed version IDs. POST requires Evaluator role and CSRF.
GET /api/evaluations/{evaluation_id}Authorized references only: participants see their own; the creating evaluator sees all four.

Submitted documents contain schema_version (1), kind, name and config only. The repository's docs/PHASE_2_FORMAT.md defines each role's narrow format and visibility rules. No artifact update/delete endpoints exist.

Web showcase routes

Authenticated fixture execution, no isolated workers. State-changing API calls require X-CSRF-Token.

POST /api/evaluations/{id}/runs — empty JSON object, creating Evaluator only.

GET /api/runs/{id}/report — permitted aggregate report and own references.

GET /api/runs/{id}/evidence — creating Evaluator only; modified=true exports a changed copy.

POST /api/runs/{id}/verify — source: original or modified_copy.

GET /api/verification-key — public PEM for authenticated Evaluators.

Offline verification: uv run --locked python -m aegislab.evidence BUNDLE --public-key TRUSTED_KEY
